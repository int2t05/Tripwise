# ADR-0019：浏览器范围内的 Computer Use

| 项 | 内容 |
|---|---|
| 状态 | 网页范围自动化、可视光标和阶段显示已实现；自动导航有界，超时内容降级为部分来源；小红书登录态内容未验收 |
| 日期 | 2026-11-06 |
| 关联需求 | PR-02、PR-04、UX-06、ADR-0008、ADR-0016 |

## 决策

本 ADR 决定提供网页范围的 Browser Use，不提供控制整台电脑或其他应用的通用 Computer Use。

Agent 自动导航最多等待 20 秒。Electron `webContents.loadURL()` 的 Promise 在页面完成加载时才结束，可能被不影响正文读取的慢资源拖住；超过上限后 Tripwise 调用 `stop()`，读取当前稳定显示的页面内容。该内容与页面来源标记为 `partial`，不生成事实证据摘录，也不用于绑定动态事实；进度区明确显示读取的是当前可见内容。用户手动导航不受此上限影响，可继续浏览或刷新。[Electron `webContents.loadURL`](https://www.electronjs.org/docs/latest/api/web-contents#contentsloadurlurl-options)

默认走 DOM 优先流程：Agent 在用户可见的同一 `WebContentsView` 中导航、读取可见正文/标题/链接、有限滚动，以及操作当前快照列出的同站 GET 搜索框和公开展开按钮。首次浏览工具运行时自动展开右侧面板并切到网页，方便用户观察。导航、开链接、搜索/展开和滚动会在一次工具结果中附上动作后的正文与链接；只有用户手动切页或确需重读时才调用独立快照，连续操作无需再单独调用快照工具。中央对话显示动作和完成状态，右侧状态行显示当前动作及结果，并同步展示打开、定位、移动、点击、滚动和读取阶段；阶段码来自隔离脚本，不携带网页文字或搜索词。执行链接、搜索、展开或滚动时，在网页内跟随最近快照确认的 DOM 目标显示非交互指针和目标高亮。滚动期间指针固定在视口并标明方向；等页面位置稳定后再读取，完成态保留到下一动作或任务结束。减少动态效果时使用即时滚动。位置由固定脚本从已校验元素计算，不接受模型坐标，也不移动系统光标；任务结束、停止或截图读取前移除标记，搜索词不显示。来源卡保留可复核结果。搜索摘要和图像线索只在内容层级不完整时显示状态标签；完整网页正文不再重复加标签。沿用现有进度区和来源栏，不新增另一套工具日志。

快照里的网页链接只以短期编号交给模型（例如 `l1`）；真实地址留在主进程内存，并且只在当前快照页仍有效时可打开。页面原地重绘导致已记录 DOM 节点脱离时，浏览器依次按地址和文案精确匹配、同地址且邻近上下文唯一匹配、唯一同地址链接恢复目标；仍有歧义时停止。目标在视口外时先等待目标元素实际移动并稳定；页面自带多个滚动容器时逐层定位目标，再检查页面视口。减少动态效果时使用即时滚动。定位完成后才显示指针并继续开链；失败会记录固定阶段，区分滚动未开始、未稳定和仍在视口外。页面 URL 已变、地址不唯一或目标无法恢复时停止并要求重新读取快照。搜索结果卡片的邻近可见文字最多 140 字，随候选链接进入模型上下文，帮助判断导航目标；它仍只是网页线索，不会增加来源正文摘录或事实证据。自动回退复用导航已读取的快照和编号，不再额外读取一遍。搜索回退按查询意图至多跟进一条快照链接：景点按地点、访问信息词和来源域名线索选页，餐饮与社区攻略只选相关社区页面，交通只选政府域名页面。链接以快照编号打开，原始正文作为来源保存；搜索摘要只用于发现链接。普通网站的敏感查询参数在加载前剔除；`xiaohongshu.com` 与 `www.xiaohongshu.com` 笔记链接只在本机来源记录中保留 `xsec_token`，模型上下文、工具输出和运行日志不包含该参数。用户主动导出的来源仍按原来源策略保留链接。

工具结果日志记录固定动作码和失败阶段，用于区分导航失败、链接目标失效与正文不可读；评测器只输出这些阶段的计数，不记录来源地址、链接文字或浏览器错误原文。整页变化或同地址链接不唯一时仍需重新读取快照，不使用旧编号继续导航。

模型请求组装时会按工具调用顺序保留当前仍可操作快照的编号，清除导航、滚动或页面交互前快照中的过期编号。已离开的搜索结果页会压至最多 2,400 字并移除失效链接/控件目标；当前快照仍可继续操作。较早的已完成研究记录可折叠进旅行来源上下文；最近整批并行结果和当前浏览器快照仍保留。该压缩只生成本轮请求副本，不改写可恢复的工具历史；运行日志只记数量和实际节省字符数。完整规则见[技术架构](../TECH.md)。

搜索结果页工具输出保留最多 12,000 字正文、30 条可见链接和每条链接最多 140 字的邻近文字；内部回退选链扫描同一快照最多 80 条链接，避免前部导航项遮住后续结果。链接以快照编号继续导航。事实来源摘录仍最多 2,400 字，来源卡摘要最多 800 字。邻近文字不提升来源内容级别或事实证据等级。

用户明确请求小红书时，Agent 直接在同一隔离 WebView 打开小红书公开站内搜索页，不依赖通用搜索引擎是否收录笔记。结果页按 `snippet` 处理，只用于发现当前快照中可见的笔记链接；来源卡明确标为“搜索摘要”。Agent 最多打开一条匹配笔记并读取可见正文；正文页作为社区来源展示，不额外叠加“全文”等标签。笔记 URL 的 `xsec_token` 只在主进程内保留给当前链接导航；模型请求与运行日志不含令牌。若页面要求登录或验证，自动读取停止，用户可手动接管并导入当前页。

视觉读取已作为默认关闭的可选工具实现。用户开启后，Agent 先用同一模型识别合成测试图；探测通过才截取当前 WebView 视口并发送给模型。截图压缩为最长边不超过 1,440 像素、2 MB 以内的 JPEG；每轮最多读取三次。截图只在内存中传递；模型摘要与原页面链接作为“图像线索”来源保存，明确标记未核验，不保存截图，也不参与开放时间、票价、交通等动态事实核验。2026-09-23 当前配置的 glm-5.3-flash 通过一次真实合成图输入测试；[火山方舟模型说明](https://console.volcengine.com/ark/region%3Acn-beijing/docs/agent-plan-personal-plan-overview)也列明该型号支持图片输入。其他兼容模型和真实网页线索质量仍待验收。

Agent 不输入账号/密码、不自动登录或处理验证码，也不执行任意坐标点击、键盘注入、下载、发布、点赞、收藏、评论、预订或支付。网页载入后由隔离浏览器在本机检查可见正文开头最多 800 字，只对明确登录/验证提示分类；检测文本不发送或保存。检测到后在网页栏显示状态、禁用导入，阻止该来源的 Agent 同源自动导航，并拒绝把门槛页保存为旅行来源。用户可在 Agent 浏览期间点击“停止并接管”，取消当前规划后在可见 WebView 内手动登录、浏览并导入当前页文字；研究会话使用 Electron 内存 Session，不读取系统浏览器 Cookie，关闭应用即清除。Agent 的交互目标始终来自最近一次 DOM 快照并在执行前复核；验证码或站点拦截仍由用户决定是否换公开来源。

研究浏览器是应用内共享会话，主进程同一时间只接受一轮 Agent 规划。Agent 运行期间，隔离会话在请求发出前拦截所有非 GET/HEAD 请求，包括页面脚本自行发起的请求；结束或取消后恢复用户手动浏览。这样页面脚本不会借 Agent 打开页面的时机提交写入请求，安全搜索仍使用同站 GET 表单。

小红书 OpenCLI 是独立、默认关闭的试点：它可通过 [Browser Bridge](https://github.com/jackwener/OpenCLI/blob/main/docs/guide/browser-bridge.md) 操作用户已登录的 Chrome，与 Tripwise 右侧隔离 WebView 不共用会话，也不会把外部 Chrome 截图送入 Tripwise 模型。Chrome Cookie 不导入 Tripwise 配置或旅行资料；OpenCLI 和扩展仍以当前账户权限运行。官方开放平台授权页最近更新时间为 2026-03-29；该页目前只列出 `basic_info` 已开放，`read_notes` 为规划中。Tripwise 不将 OpenCLI 或可见网页描述成官方笔记 API。[官方授权范围](https://openaccount.xiaohongshu.com/docs/scope) 用户也可在 Tripwise 右侧隔离浏览器手动登录并尝试读取；会话只保留到应用关闭，实际登录态和笔记抽取尚未验收。登录墙出现时 Agent 停止同站自动导航，用户需手动继续或改用公开来源；不绕过验证码或访问限制。

2026-09-24 的本机真实页面复核中，小红书搜索页返回 `login-required`，可见正文 62 字，未返回攻略笔记；设置中 OpenCLI 未启用，系统 PATH 也未找到 `opencli`。这证明当前公开 WebView 会遇到登录门槛，不代表 OpenCLI 或登录后的正文读取已通过。保留内存会话是有意选择：当前 `electron-builder.yml` 关闭 Cookie 加密；改成持久 Electron Profile 会把站点登录态落盘。开启 Electron Cookie 加密则依赖 macOS Keychain，且 Electron 文档提示未稳定签名的构建可能重复请求授权。因此本版本不持久化内置浏览器登录态，也不接管系统桌面。[Electron Session](https://www.electronjs.org/docs/latest/api/session)、[Electron Cookie 加密与代码签名](https://www.electronjs.org/docs/latest/tutorial/code-signing)。

2026-09-24 北京实跑再次尝试公共社区回退 1 次，读取 12 页正文与 8 条摘要，仍无笔记级小红书正文。Agent 的状态和右侧页面可观察，但这不代表该站点可以匿名访问；保持登录后手动接管与当前页导入作为可用路径。2026-09-25 的上下文裁剪回归与完整北京复跑结果见[旅行评测](../../evaluation/TRAVEL-CASES.md#2026-09-25-北京复跑过期浏览器搜索页压缩)。

## 选择依据

- **沿用 Electron 研究浏览器：** 现有页面、DOM 读取、出口保护、权限拒绝、进度状态和停止流程都在同一边界内；Electron `webContents.capturePage()` 可截取当前页，`executeJavaScriptInIsolatedWorld()` 可运行固定读取脚本。[Electron WebContents](https://www.electronjs.org/docs/latest/api/web-contents)
- **DOM 优先、视觉补充：** Microsoft Playwright MCP 通过结构化可访问性快照操作页面，适合做工具行为参考；截图只用于当前视口线索，不转换成坐标动作。[Playwright MCP](https://github.com/microsoft/playwright-mcp)
- **不另接通用浏览器 MCP：** Tripwise 已有可见、隔离、会话内浏览器和统一来源存储；另开 Playwright/MCP 浏览器会形成第二个页面、登录态和来源生命周期，用户无法在同一侧栏核对 Agent 正在读取的内容。需要外部浏览器时仍可由用户在应用内配置 MCP，但不是默认 Computer Use 路径。
- **不接管系统桌面：** Electron `sendInputEvent()` 要求主窗口聚焦，会把页面动作扩展到依赖焦点的输入控制；这既不需要也不适合旅行资料读取。[Electron 输入事件](https://www.electronjs.org/docs/latest/api/web-contents)
- **小红书独立处理：** 当前官方授权范围只开放 `basic_info`，`read_notes` 标为规划中；默认关闭 OpenCLI 只作为用户自选的浏览器适配器，不称为官方 API，也不绕过登录、验证或站点限制。[官方授权范围](https://openaccount.xiaohongshu.com/docs/scope)
- **不持久化登录态：** 持久 Electron Profile 会保存站点 Cookie；当前构建关闭 Cookie 加密。macOS Electron Cookie 加密依赖 Keychain，未稳定签名时还可能重复弹授权。因而继续使用内存会话，优先保住权限边界和可清理性。[Electron Session](https://www.electronjs.org/docs/latest/api/session)、[Electron 代码签名](https://www.electronjs.org/docs/latest/tutorial/code-signing)
- **未来通用登录站点：** 若真实用户需求证明手动导入和站点连接器不够，再评估浏览器扩展。Chrome `activeTab` 只在用户主动调用后短时授权；跨页面自动读取需要额外站点权限与本机桥接，需按域名逐个授权，不开放调试端口或全桌面坐标控制。[Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)

## 验收条件

1. 常规网页只走 DOM 快照；视觉读取默认关闭，探测合成图通过后才捕获网页截图。
2. 首次浏览工具调用自动打开右侧网页页签；操作目标由已校验 DOM 定位，页面内指针先移动并高亮、再显示按下反馈。右侧显示打开、定位、移动、点击、滚动和读取阶段，滚动时方向与状态可见，滚动稳定后才读取页面，减少动态效果时使用即时滚动。页面标题、动作和结果状态在中央可见，右侧显示同一网页；停止操作能取消正在执行的浏览。系统光标不移动。
3. 截图字节不进入数据库、恢复数据、日志、来源备份或用户导出的旅行 JSON；视觉摘要以“图像线索”来源保留原页链接。
4. 页面开头的明确登录/验证码/拦截状态可见、阻止导入和同源 Agent 导航；不触发绕过或非只读操作。
5. 视觉识别得到的动态数值仍显示待核验，直到绑定到合格网页正文或权威结构化来源。
6. 用户可在 Agent 浏览时停止并接管临时 WebView，之后使用地址栏和历史导航；会话不跨应用重启保留，Agent 不自动填写登录凭证。
7. 来源卡区分搜索摘要、网页正文与图像线索；摘要和图像线索不可被误认为已读取原文。
8. Agent 运行期间拒绝并发规划，并阻止研究网页发出非 GET/HEAD 请求；规划结束后用户可继续手动浏览。

DOM 控制与视觉输入路径已实现；Electron E2E 验证合成图探测、真实 WebView 截图发送、视觉线索来源保存、截图不落盘、登录墙状态/导入拦截/同源 Agent 导航阻止、快照链接编号跟进与查询参数隔离，以及用户手动恢复后可继续浏览；新增验证主进程拒绝并发 Agent 运行且页面脚本 POST 未到达网页出口。当前配置的 glm-5.3-flash 也已通过实时合成图输入测试。2026-09-24 回归发现通用敏感参数过滤会误删小红书笔记 `xsec_token`，导致站内搜索结果无法跟进原文；已改为只在主进程导航目标保留此参数，并让用户点名的小红书搜索直达站内结果页。定向回归 47 项通过，覆盖结果页标为 `snippet`、笔记正文保存为社区来源及令牌不进入模型请求。随后真实 Electron 页面复核显示未登录搜索只有 62 字并要求登录；本机未配置 OpenCLI，因此没有验证小红书笔记正文。受控页面测试通过不等于真实站点读取通过。实现状态见[项目进度](../../PROJECT-STATUS.md)，既有浏览器能力边界见[ADR-0016](0016-visible-research-browser-control.md)，小红书试点见[ADR-0008](0008-xiaohongshu-opencli-connector.md)。
